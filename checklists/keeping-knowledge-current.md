# Keeping a project current (Domain 5, objective 5.4)

- [ ] Every file in the project has an **owner**.
- [ ] Every file has a **review date**, and its version or year in both the file name and the document.
- [ ] Replaced files are **removed**, not left next to the new ones.
- [ ] When a process changes, the **instructions or Skill** are updated, not just one chat.
- [ ] After any change, ask a question you already know the answer to, and check the reply.

Example instruction line (from the course): "Price list: use price-list-2026 only. Owner: Tessa Morrow. She checks it on the first Monday of each month and replaces it when a new list is issued. If a price list in the files has expired, say so and don't quote from it."
