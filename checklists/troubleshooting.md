# Troubleshooting a weak output (Domain 7)

Diagnose before you rewrite. Go down the list:

| Cause | Typical sign | Fix |
|---|---|---|
| **Missing context** | invented dates or names; generic answers; a chat started outside the project | work in the project; add the facts or connect the source |
| **Vague task** | wrong format, wrong length, wrong reader | say the task, audience, format, constraints and what "done" means |
| **Wrong feature or model** | slow and heavy for a quick job, or slips on a complex one | match the feature and model to the job (see Domain 3) |
| **Stale knowledge** | one specific old fact keeps coming back | replace the file, name an owner and a check date |
| **Overflowing chat** | early details forgotten; topics bleeding into each other | ask for a handoff summary and continue in a fresh chat |
| **Broken input** | impossible values, wrong row counts | get a clean copy of the source |

## Make the fix stick
| The feedback is about… | Put the fix in… |
|---|---|
| a fact that changed | the project knowledge (replace the file) |
| a rule for this project | the project instructions |
| how one kind of task is done | the Skill |
| a one-time preference | just this chat |

Then re-test with a request whose correct answer you already know.
