# Templates

- `project-instructions.md`: the project instructions from Domain 5, plus a checklist for writing your own.
- `skills/bramblewick-proposal-style/SKILL.md`: the proposal Skill from Domains 5 and 7 (version 2, with the service-and-tax rule). To add it in Claude: Customize › Skills › Add › Create a skill, and paste the name, description and steps. Or zip the folder and choose Upload skill. If your organization has an AI policy, check whether Skills from outside need approval first.
