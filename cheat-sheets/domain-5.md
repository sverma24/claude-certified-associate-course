# Domain 5: Configuration and knowledge management (12%)

Claude Certified Associate Foundations course · cheat sheet

## 5.1 Setting up a project from zero

A project is a welcome pack. Name it, keep account memory out if it's client work, write clear instructions, and upload only the files that matter.
Avoid: 1. no instructions, so every chat starts generic · 2. uploading everything 'just in case' · 3. two clients in one project

## 5.2 Uploaded files or connected apps

Upload what's stable, connect what's living, and keep personal data out until it's cleaned. Connectors see what their account sees, and ask before they act.

## 5.3 Instructions that work, and where Skills fit

Instructions are the house rules, knowledge is the filing cabinet, and a Skill is the recipe card. Write rules you can check, and say which one wins when two conflict.
Avoid: 1. vague rules nobody can check · 2. putting facts in instructions and rules in files · 3. pasting a long procedure into every project instead of making a Skill

## 5.4 Keeping it current

Knowledge goes stale like food in a fridge. Give every file an owner and a check date, remove what's replaced, and prove each fix with a question you know the answer to.
